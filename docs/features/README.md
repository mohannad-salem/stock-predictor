# Feature goals

One file per feature, written with the design partner. Template:

```
# Feature: <name>

Goal: what the user can do when this is done, in one or two sentences.

Acceptance criteria:
1. ...
2. ...

Out of scope:
- ...
```

Then commit it to a new milestone branch and ask the project to plan it (workflow/README.md, steps 2 and 3).
