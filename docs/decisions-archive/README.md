# Decisions archive

One file per finished milestone, named after its slug (for example `user-login.md`), holding that milestone's full decision entries: question, options, decision and reasoning.

The rules themselves stay in `docs/decisions.md` under "Rules in force", one line each, so agents don't read this folder by default. Open a file here only when you need to know why a decision was made or which options were turned down.

The design partner writes these files in a "milestone close" session, before Mohannad merges the milestone into main.
